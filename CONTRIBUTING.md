# Contributing

This repository is primarily a publication-reproducibility archive. Bug reports, reproducibility issues, and clearly documented methodological improvements are welcome.

Before opening an issue, please include:

1. operating system and Python version;
2. exact repository release/tag;
3. package environment (`conda env export` or `pip freeze`);
4. the script and command that failed;
5. the full error message; and
6. whether your source datasets match `data/source_manifest.csv`.

Do not upload or attach raw third-party datasets whose provider terms restrict redistribution. Instead, identify the provider, version, tile ID, or Earth Engine dataset ID.

For scientific questions about the manuscript, contact Fadzlur-Nijar A. Adju at fadzlur-nijar.adju@msusulu.edu.ph.
