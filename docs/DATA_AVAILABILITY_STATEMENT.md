# Data and code availability statements

## Before the Zenodo DOI is minted

> The analysis code, Google Earth Engine export scripts, lightweight derived summary data, and reproducibility documentation associated with this study are prepared for public release at https://github.com/Remagorp2016/sulu-mangrove-dynamics-geoai. Raw third-party source datasets are not redistributed; acquisition identifiers and provider links are documented in the repository. A versioned Zenodo DOI will be added before publication.

## After the Zenodo DOI is minted

Replace `10.5281/zenodo.XXXXXXX` below with the **version DOI** for the exact release used in the manuscript:

> The analysis code, Google Earth Engine export scripts, lightweight derived summary data, and reproducibility documentation associated with this study are openly available in the GitHub repository https://github.com/Remagorp2016/sulu-mangrove-dynamics-geoai and the archived Zenodo release (https://doi.org/10.5281/zenodo.XXXXXXX). Raw third-party source datasets are not redistributed; the repository documents the exact product versions, tile identifiers, Earth Engine dataset IDs, and acquisition links required for reproduction.

## Recommended manuscript wording for JEM

The second version is preferred because it distinguishes original reproducibility materials from third-party source data and avoids implying that provider-restricted/raw rasters have been re-hosted.
