# Data and code availability

The analysis code, Google Earth Engine export scripts, lightweight derived summary data, and reproducibility documentation associated with this study are openly available in the GitHub repository:

https://github.com/Remagorp2016/sulu-mangrove-dynamics-geoai

A permanent archived release is available on Zenodo:

https://doi.org/10.5281/zenodo.22690576

Raw third-party source datasets are not redistributed. The repository documents the exact product versions, tile identifiers, Earth Engine dataset IDs, and acquisition links required for reproduction.

## Recommended manuscript wording

> The analysis code, Google Earth Engine export scripts, lightweight derived summary data, and reproducibility documentation associated with this study are openly available through GitHub and archived on Zenodo (https://doi.org/10.5281/zenodo.22690576).
